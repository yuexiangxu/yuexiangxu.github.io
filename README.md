## Moon display

Today's phase angle and illuminated fraction are calculated with the locally bundled
[Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy) (MIT license;
license preserved in the vendor file). Lunar age is elapsed time since the preceding
calculated new moon, rather than a fraction of an average month. Calculations refresh
each minute and calendar dates use `Asia/Shanghai`. The graphic uses a standard
northern-hemisphere orientation; it does not simulate tilt relative to the local horizon.

Beijing's displayed latitude, 39.93°N, rounds the 39°56′N listed in the
[Beijing government overview](https://www.beijing.gov.cn/renwen/bjgk/).
